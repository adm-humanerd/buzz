# Buzz mobile terminology

Terms established while developing the Buzz mobile vision.

## Language

**Cached content**:
Buzz content retained on a device for use without connectivity.

**Draft**:
A composed message that the user has not yet chosen to send.

**Pending action**:
A user-requested operation, such as sending a message, that has not yet completed. A pending send is distinct from a draft.

**Shared behavioral semantics**:
The rules defining the meaning of Buzz behavior across clients, such as what counts as unread, channel ordering, and autocomplete membership and ordering. Presentation and interaction can differ by platform.

**Pending send**:
A message the user has chosen to send whose relay acceptance has not yet been confirmed, including when acceptance is uncertain.

**Sent**:
A message whose acceptance by the relay has been confirmed. This does not imply receipt or reading by another user or device.

**Failed send**:
A send that requires intervention to complete.
